# VoiSee 12.2.3 — Voice Changer Studio Flow

- Redesigns the Voice Changer tab around the approved Studio Flow concept.
- Moves presets into a dedicated searchable, scrollable left rail.
- Keeps noise suppression and Voice Monitor visible in a compact top control strip.
- Replaces the vertical processing stack with a horizontal, horizontally scrollable signal chain.
- Changes effect drag/reorder insertion math from vertical Y position to horizontal X position.
- Redesigns active effects as compact chain cards with drag, value, slider, bypass and remove controls.
- Moves the scalable Effect Library below the chain and adds search plus category filters.
- Adds `Bypass All` for the active chain and session-only per-card bypass toggles.
- Preserves the VoiSee 12.2.2 DSP order, effect values and preset schema 2 storage contract.

The UI remains visually unbounded for future effect types. Duplicate instances of one effect type are still outside the 12.2.3 data-model scope.
