# VoiSee 12.5.0 — Advanced Voice Effects

Experimental pre-release branch based on the stable 12.4.3 line.

Added ordered realtime voice effects:

- Gender Male — dedicated pitch shifter plus shifted vocal-resonance bank.
- Gender Female — dedicated pitch shifter plus shifted vocal-resonance bank.
- Possessed — low pitch-shifted delayed parallel voice with dark modulation.
- Megaphone — narrow-band voice path, saturation and compression.
- Helicopter — hard rotor/chopper amplitude modulation.
- Cyborg — metallic carrier modulation plus nonlinear and digital quantization stages.
- Broken Radio — band-limited voice, periodic dropouts, crackle and quantization.
- Vocoder — six-band envelope analysis driving a synthetic harmonic carrier.

All effects participate in the existing ordered processing chain, live preview, user settings and schema-2 voice presets. The 12.4.x DPI/scroll and Scene button fixes are retained.
