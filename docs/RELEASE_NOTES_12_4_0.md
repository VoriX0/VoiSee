# VoiSee 12.4.0

## Changes

- Restored the SoundBoard track context menu after the migration to `ListView`. Right-click handling now explicitly selects the clicked track and opens its existing context menu at the pointer position.
- Media Bridge no longer scrolls: both vertical and horizontal scroll modes are disabled and both scroll bars are hidden.
- Keeps the 12.3.3 buildfix 6 Per-Monitor V2 DPI-awareness fix that corrected native scroll hit-testing at 125% Windows scaling.
- Synchronized application, installer, and release-build version metadata to 12.4.0.
