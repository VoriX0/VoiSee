# VoiSee 12.4.1

## Voice Changer

- Expanded Effect Library with eight new real-time effects: Low Pass, High Pass, Chorus, Flanger, Phaser, Vibrato, Doubler, and Ring Mod.
- New effects participate in the ordered DSP chain, live preview/settings path, persistence, and schema 2 voice presets.
- Increased drag-handle hit areas in both Effect Library and Processing Chain while keeping the visual grip compact.

## Baseline preserved

- Keeps the 12.4.0 SoundBoard context-menu fix.
- Keeps Media Bridge without a scroll container.
- Keeps PerMonitorV2 DPI awareness required for correct native scrolling at Windows scaling such as 125%.
