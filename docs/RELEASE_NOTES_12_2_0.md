# VoiSee 12.2.0 — Effect Cards UI Prototype

This is a visual prototype of the future Voice Changer effect-card workflow.

## Layout

- Processing chain occupies 36% of the Effects workspace.
- Effect library occupies 64% on the right.
- A microphone marker starts the signal path.
- A speaker marker ends the signal path.
- The chain contains compact equal-width cards and a dedicated drop zone.
- Existing voice processing controls are displayed as equal-sized cards in the right library.
- Search and category controls are included as layout placeholders.

## Scope

This build is intended to evaluate proportions, density, card size, scrolling and overall visual balance before implementing drag-and-drop and a mutable DSP chain.

The audio algorithms and current fixed processing order are unchanged.
