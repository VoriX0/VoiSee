# VoiSee 12.2.1 — Effect cards interaction prototype

- Implemented drag from Effect Library into the Processing Chain.
- Processing Chain now starts empty; Voice Gain and Pitch are no longer inserted by default.
- Library controls now act as a one-effect-at-a-time preview and are not saved until the card is dropped into the chain.
- The preview card is lighter and is replaced whenever another effect is tested.
- Presets were moved directly below the Effect Library.
- Existing DSP algorithms were not reordered in this prototype.

Build and automated tests were not run.
