# Проверки VoiSee 14.1.1

Среда: Windows 10.0.26200, Intel i7-14650HX, .NET SDK 9.0.315 / runtime 8.0.28. Проверялась ветка `14` на базе `b1829bb`.

## Автоматические проверки

- Release build: успешно, 0 предупреждений и ошибок.
- Self-contained publish win-x64: успешно, runtime и native DLL включены.
- `dotnet run --project tests/VoiSe.RegressionTests -c Release --no-restore -p:UseSharedCompilation=false`: **14 PASS**.
- `git diff --check`: успешно.
- Inno Setup 6: установщик собирается; включён полный комплект VB-CABLE для optional install. Установщик не запускался и драйвер не устанавливался.

Состав регрессионных проверок:

1. Wrap/overflow фиксированного ring buffer, порядок samples и счётчик dropped samples.
2. LRU-вытеснение, инвалидирование прошлой ревизии и Clear.
3. Загрузка библиотеки из 50 четырёхсекундных WAV: удержание кеша **66 048 000 bytes**, ниже бюджета 67 108 864 bytes. Новые файлы вытесняют старые.
4. Завершение звука при отключённом monitor output.
5. Раздельные virtual/monitor громкости и virtual delay.
6. Восемь активных коротких звуков, два выхода: **0 allocated bytes** в измеряемых steady-state Read.
7. Stop/Dispose и отказ Play у закрытого транспорта.
8. Длинный файл: потоковое чтение, перемотка, pause/resume, Stop и отсутствие полного файла в PCM-кеше.
9. Потоковый ресемплинг 44.1 → 48 kHz; проверяется установившийся сигнал, а не начальный transient фильтра.
10. Возврат к началу длинного loop.
11. Освобождение decoder file handles после отмены.
12. JSON backup/recovery с сохранением повреждённого оригинала.
13. Сбой atomic commit на заблокированном target: предыдущий файл остаётся целым, временный файл удаляется.
14. Заблокированный replacement source: старый трек/ссылка остаются; последующая успешная замена работает.

## Диагностическая оболочка

Собрана отдельная копия UI с изолированными settings/library/logs, отдельным single-instance именем, без автозапуска engine, Discord mute и autostart repair. Изменения диагностической копии не включаются в production-код.

Выявлен зависимый от расположения запуска нативный сбой `0xc0000374`: полный UI из длинного каталога сборки иногда открывался и падал при завершении, иногда падал на создании окна. Ошибка воспроизвелась и на сохранённой контрольной сборке 12.5.1, в sandbox и при отдельном запуске вне sandbox. Простая WinUI window без полной оболочки завершалась успешно.

Перенос **того же набора бинарных файлов** в короткий каталог `artifacts/smoke14` дал штатный запуск и выход с code 0. Это подтверждает условие воспроизведения, но без native dump не доказывает точную причину повреждения heap. Не следует считать длинный путь или WinUI runtime полностью исправленными; для ручной проверки использовать короткий путь и стандартный каталог установщика.

Повторный прогон чистой диагностической копии из короткого пути: 35 секунд, 69 process samples, 39 samples steady-state между 10-й и 30-й секундами; **exit code 0**, запись `Program.Main finished normally`. Средние показатели: **180,31 МиБ Working Set**, **106,00 МиБ Private Bytes**, **0,80% одного ядра CPU**. Это не строгий A/B-бенчмарк; небольшую разницу с прежним idle-тестом нельзя считать доказанной экономией RAM полного приложения.

Результаты сохранены в `audits/14.1.1/ui-idle.json` и `audits/14.1.1/regression-results.txt`. Замеры этой копии не являются полной RAM/CPU-нагрузкой программы с библиотекой и устройствами и не доказывают отсутствие длительных утечек.

## Ручные проверки после установки

- Версия 14.1.1; запуск, восстановление из трея, полный Exit.
- USB/Bluetooth подключить/отключить → Refresh без перезапуска. Списки соответствуют Windows endpoint; исчезнувший выбранный input не продолжает показываться работающим.
- Если выбранный input/output остался тем же, Refresh не прерывает музыку и сцены. Если исчез — UI и действующий маршрут согласованы, ошибки понятны.
- Voice Monitor Off, отдельное прослушивание SoundBoard, virtual mic mute и отсутствие дубля Media Bridge в наушниках.
- WAV/MP3/OGG, короткий и длинный файл, loop, pause, seek, сцены с overlay, большой набор звуков.
- Смена шумоподавления, presets/effect reorder/themes и разные DPI без регрессий.
- Повторные Start/Stop, исчезновение окна Media Bridge во время запуска, закрытие во время фонового декодирования.
- Существующая библиотека 12.5.1, сохранение/импорт/редактор, повреждённый JSON, отказ записи/полный диск.
- Длительный прогон 60 минут и затем 8 часов с измерением retained heap/private bytes, handles, threads и underruns.

Эти пункты не отмечены выполненными автоматически: стенд не открывал физические аудиоустройства и не менял пользовательские данные.
