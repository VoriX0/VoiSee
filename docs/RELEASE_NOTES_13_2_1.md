# VoiSee 13.2.1

## AI Voice layout refinement
- moved Gaming / Balanced / Quality into the center column directly above Online Library;
- selector width now exactly follows the Online Library panel;
- My AI Voices actions use a fixed 2:1:1 layout: Create from Audio occupies half, Import and Open Folder split the other half equally;
- Model Manager actions fill the full panel width in four equal columns.

## AI Voice storage
- default storage is now `%LOCALAPPDATA%\VoiSe\AI Voices`;
- first Create/Import no longer asks for a storage folder;
- Settings now contains an AI Voice Storage card with Change Folder and Open Folder;
- changing storage switches the active library to the selected directory without moving or deleting files from the previous directory.
